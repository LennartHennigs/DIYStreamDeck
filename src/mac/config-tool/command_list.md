# Action Commands

## Folder
- close_folder

## Spotify
- spotify.play
- spotify.pause
- spotify.playpause
- spotify.next
- spotify.prev
- spotify.volume_up
- spotify.volume_down

## Hue
- hue.toggle 'lamp name'
- hue.turn_on 'lamp name'
- hue.turn_off 'lamp name'

## Sounds
- sounds.play 'filename.mp3'
- sounds.stop
